## BigCommunity

**BigLinux for everyone.** A Linux distribution built on [BigLinux](https://www.biglinux.com.br), with GNOME, XFCE and Cinnamon editions. It was born from a request of our own community: people who love the Big way of doing things but prefer a desktop other than Plasma.

🇧🇷 *O BigCommunity é uma distribuição baseada no BigLinux, com edições GNOME, XFCE e Cinnamon, feita pela comunidade para a comunidade.*

#### How we work

- Every package is built on CI in a clean container, signed with our [keyring](https://github.com/big-comm/community-keyring), and goes through `testing` before it reaches `stable`.
- Our kernel, [linux-big](https://github.com/big-comm/big-kernel), follows kernel.org on its own and is validated in `testing` first.
- Every edition is described in one place, [iso-profiles](https://github.com/big-comm/iso-profiles), and built into an ISO by [Build ISO](https://github.com/big-comm/build-iso).
- Our apps ship in 29 languages, translated with [LangForge](https://github.com/big-comm/LangForge).

#### Start here

- [**AshyTerm**](https://github.com/big-comm/ashyterm): terminal with saved sessions, splits and remote tunnels
- [**Big Shot**](https://github.com/big-comm/gnome-shell-big-shot): screenshots, annotation and screen recording for GNOME
- [**Big Gnome Center**](https://github.com/big-comm/big-gnome-center): layouts, themes and effects for GNOME in one app
- [**Ashy Pass**](https://github.com/big-comm/ashypass): private password manager written in Rust
- [**AppImage Creator**](https://github.com/big-comm/appimage-creator): turns any app into an AppImage
- [**GitRepo**](https://github.com/big-comm/gitrepo): the tools we use to build packages and ISOs
